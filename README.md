# 별빛 수집가

여러 플레이어가 같은 3D 맵에서 서버가 떨어뜨리는 별똥별 조각을 먼저
수집하는 실시간 웹게임입니다. 기획서의 1차 범위(Phase 0~4)에 더해
실제 GLB 에셋·채팅·사운드·점수 저장까지 들어가 있습니다.
별똥별 등급과 맵 확장은 아직 없습니다.

## 구현된 핵심 루프

1. 닉네임을 입력하고 공개 방에 자동 입장합니다.
2. WASD로 이동하고 Shift로 달리며, 우클릭 드래그와 휠로 카메라를
   조작합니다.
3. 서버가 45~90초 사이의 무작위 간격으로 별똥별을 예고하고 같은
   위치에 충돌시킵니다.
4. 충돌 지점 주변에 서버가 확정한 조각 4~6개가 생성됩니다.
5. 2m 안에서 E를 누르면 서버가 거리·존재 여부·반복 요청을 검증합니다.
6. 동시에 요청해도 먼저 처리된 한 명만 점수를 받고 모든 화면에서
   조각이 제거됩니다.

## 요구 환경

- Node.js 22 이상 권장
- pnpm 11.9.0 (`corepack enable` 후 루트의 `packageManager` 사용 가능)
- WebGL 2를 지원하는 데스크톱 브라우저

## 설치 및 실행

저장소 루트에서 한 번 설치하고, 한 명령으로 클라이언트와 서버를 함께
실행합니다.

```bash
pnpm install
pnpm dev
```

- 게임: <http://127.0.0.1:5173>
- Colyseus 서버: `http://localhost:2567`

## 무료 배포

Vercel Hobby 프론트엔드와 Render Free 서버 배포 설정이 포함되어 있습니다.
Render를 먼저 배포한 뒤 해당 주소를 Vercel의 `VITE_SERVER_URL` 환경 변수에
입력합니다. 화면별 설정 방법은 [`DEPLOYMENT.md`](./DEPLOYMENT.md)를 참고하세요.

브라우저 창이나 탭을 여러 개 열고 서로 다른 닉네임으로 접속하면 같은
공개 방에서 플레이할 수 있습니다. 한 방의 최대 인원은 8명입니다.

## 환경변수

기본값으로 바로 실행할 수 있습니다. 주소나 포트를 바꿀 때는
[`.env.example`](./.env.example)을 참고하세요.

| 변수 | 기본값 | 용도 |
|---|---:|---|
| `VITE_SERVER_URL` | `http://localhost:2567` | 클라이언트가 접속할 서버 |
| `PORT` | `2567` | Colyseus 서버 포트 |
| `METEOR_INTERVAL_SCALE` | `1` | 자동 검증 시 별똥별 대기시간 배율 |
| `SCORE_STORE` | `file` | 점수 저장 방식. `none` 이면 저장하지 않습니다 |
| `SCORE_STORE_PATH` | `<서버 실행 위치>/data/scores.json` | 점수 파일 경로 |

점수는 브라우저가 들고 있는 ID 를 키로 저장합니다. 계정이 없으므로 다시 온
사람을 알아볼 방법이 이것뿐이고, 브라우저를 바꾸면 기록도 새로 시작합니다.
저장소는 `apps/server/src/storage/ScoreStore.ts` 의 인터페이스로 분리해 두었으니
DB 로 바꾸려면 구현을 하나 더 만들면 됩니다. **Render Free 처럼 디스크가
재시작 때 지워지는 곳에서는 파일 저장이 유지되지 않습니다.**

`VITE_SERVER_URL`은 루트 `.env`에 둘 수 있습니다. 서버 변수는 실행
셸의 환경변수로 전달합니다. PowerShell에서 별똥별 주기만 짧게 검증하는
예시는 다음과 같습니다.

```powershell
$env:METEOR_INTERVAL_SCALE = "0.02"
pnpm dev
```

실제 플레이에서는 이 값을 설정하지 않거나 `1`로 사용하세요.

## 조작

| 입력 | 동작 |
|---|---|
| W / A / S / D | 카메라 기준 이동 |
| Shift | 달리기 |
| E | 가까운 별 조각 수집 |
| Enter | 채팅 열기 / 보내기 (Esc 로 닫기) |
| 마우스 우클릭 드래그 | 카메라 회전 |
| 마우스 휠 | 확대 / 축소 |

## 검증 명령

```bash
pnpm typecheck
pnpm test
pnpm build
```

서버 테스트는 다음 규칙을 확인합니다.

- 정상 이동 허용과 순간이동 거부
- 비정상 좌표 거부
- 조각 위치의 접근 가능성과 최소 간격
- 수집 거리 검증
- 같은 조각의 중복 지급 방지

## 프로젝트 구조

```text
apps/
  client/   Babylon.js + Vite 클라이언트
  server/   Colyseus 권한형 게임 서버
packages/
  shared/   상수, 메시지 타입, 맵 데이터, 충돌/닉네임 공통 로직
```

게임 밸런스 값은
[`packages/shared/src/constants.ts`](./packages/shared/src/constants.ts)에
모여 있습니다. 네트워크 메시지 이름과 페이로드는 shared 패키지를 통해
클라이언트와 서버가 함께 사용합니다.

## 서버 권한 범위

서버가 별똥별 시각·낙하지점·조각 위치·조각 수명·획득자·점수를
결정합니다. 클라이언트는 로컬 이동을 즉시 표현하고, 서버에 위치를
초당 12회만 전송하며, 원격 플레이어를 보간해 표시합니다. 서버는
이동속도와 맵/장애물 경계를 검증합니다.
